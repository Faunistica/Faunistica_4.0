# Инструкция для волонтёров

Наш проект посвящён оцифровке данных о биоразнообразии пауков Урала.

Подробнее о проекте: [faunistics.international](https://faunistics.international/)

Старые инструкции (versions 2.0–3.0): [Инструкция v2.0](https://faunistics.international/vol_manual) · [Инструкция v1.0 (Notion)](https://puzzling-ironclad-999.notion.site/7ce0e0d610dd4313b15389c07a7d78f5)

---

Приветствуем вас на проекте "Паутина данных"! Вам предстоит перенести данные из разнообразных арахнологических публикаций в цифровой формат: открыть файл с публикацией, найти там информацию и занести её в форму на сайте. Распознать и структурировать сведения о находках пауков из предложенных научных статей: кого, где, когда и кто нашёл?

**Технические требования для участия в проекте:**

- Доступ в интернет
- Мессенджер Телеграм
- Персональный компьютер / ноутбук
- Десктопная версия браузера (Google Chrome, Firefox, Edge, Safari, Opera)

> Корректная работа приложения на планшетах и телефонах не гарантирована!

# Регистрация и авторизация

## Регистрация через Телеграм

Для регистрации перейдите на страницу авторизации и нажмите кнопку **Войти через Telegram**. Система сгенерирует одноразовый код и покажет QR-код. Отсканируйте его телефоном или перейдите по ссылке на бота и отправьте код.

![Регистрация через Телеграм](/assets/instruction/auth1.webp)

После подтверждения кода в Телеграме вы будете перенаправлены на страницу анкеты. Заполните все обязательные поля: имя, логин, пароль, возраст, пол, языки и предпочтения в работе.

![Анкета после регистрации](/assets/instruction/auth2.webp)

## Вход в систему

В дальнейшем для входа используйте логин и пароль, указанные при регистрации. Токен авторизации обновляется автоматически — повторно входить не нужно.

![Страница входа](/assets/instruction/auth3.webp)

# Дашборд — список публикаций

После входа вы попадёете на страницу **Публикации** (дашборд). Здесь отображаются публикации, назначенные вам для обработки.

Публикации разделены на две группы:

- **Доступные для обработки** — публикации, которые вы можете начать или продолжить.
- **В очереди** — публикации, которые уже обрабатываются другими волонтёрами.

Для каждой публикации доступны две кнопки:

- **Продолжить** — перейти к форме ввода данных.
- **Завершить обработку** — перейти на страницу завершения (см. раздел «Завершение работы с публикацией»).

![Дашборд с публикациями](/assets/instruction/dashboard1.webp)

Прочитать подробности про структуру научных публикаций вы можете [здесь](https://puzzling-ironclad-999.notion.site/bf56cef08da44bd9a8465fbd2b58f5df).

# Начало работы — форма ввода данных

Нажмите **Продолжить** на нужной публикации. Откроется форма ввода данных, состоящая из двух частей: **боковая панель (сайдбар)** слева и **карточки формы** справа.

![Общий вид формы](/assets/instruction/form1.webp)

### Общие рекомендации по работе с публикацией

1. **Для начала прочитайте публикацию целиком.** Как показывает наш опыт, предварительное чтение публикации даст ответ на большинство вопросов, связанных с тем, где искать информацию о месте сбора, методах сбора и т.п.
2. В рамках проекта мы вносим в форму информацию о **НАХОДКАХ** пауков. Одна находка — это один вид, найденный в одну дату в одном месте и собранный одним методом. При этом количество особей этого вида может быть любым. Если один и тот же вид собран в разные даты или в разных местах или разными методами, то есть если в этих пунктах есть хоть какие-то отличия, то это **РАЗНЫЕ НАХОДКИ**. Соответственно, каждую из них нам предстоит внести в форму по отдельности.
3. Если возникают вопросы, не стесняйтесь обращаться к нам за помощью. Для этого можно написать в чат поддержки (кнопка **Поддержка** в шапке сайта) или обратиться к телеграм-боту с командой `/support`.

# Боковая панель (сайдбар)

Сайдбар — это список всех записей (находок) в текущей публикации. Он расположен слева от формы и всегда виден на экране.

![Сайдбар](/assets/instruction/sidebar1.webp)

## Управление записями

- **Добавить запись** — кнопка в верхней части сайдбара. Создаёт новую пустую запись.
- **Переключение между записями** — кликните на любую запись в сайдбаре, чтобы открыть её для редактирования.
- **Удалить запись** — кнопка с иконкой корзины на каждой записи. Подтвердите удаление во всплывающем окне.

## Статус записей

Каждая запись имеет статус, который отображается цветным индикатором:

| Статус | Цвет | Значение |
|--------|------|----------|
| Пустая | Серый | Запись не заполнена |
| Черновик | Синий | Запись заполнена, но не отправлена |
| Ошибка | Красный | Есть ошибки валидации |
| Готово | Зелёный | Запись успешно отправлена |

Текущая редактируемая запись выделена синей точкой и пометкой «Редактирование».

![Статусы записей](/assets/instruction/sidebar2.webp)

## Работа с Excel

В сайдбаре есть кнопка **Работа с Excel**, которая позволяет:

- **Импортировать** — загрузить записи из файла `.xlsx` или `.csv` ( Drag & Drop или выбор файла). При импорте текущие записи будут заменены.
- **Экспортировать** — скачать все ваши записи для текущей публикации в формате `.xlsx`.

![Импорт/экспорт Excel](/assets/instruction/excel1.webp)

# Автосохранение

Система автоматически сохраняет вашу работу. После каждого изменения поля через 2 секунды запись сохраняется как черновик.

Индикатор автосохранения находится в нижней части формы:

- **Сохраняется...** — идёт сохранение.
- **Сохранено в ЧЧ:ММ:СС** — запись успешно сохранена.
- **Не сохранено** — возникла проблема с сохранением.

![Автосохранение](/assets/instruction/autosave1.webp)

> Автосохранение работает для черновиков. Чтобы запись попала в базу данных как готовая, нужно нажать кнопку **Отправить** внизу формы.

При переключении между записями текущая запись автоматически сохраняется перед загрузкой следующей.

# Пространственная локализация

В карточке **Пространственная локализация** вносится вся информация о месте находки: административное деление, топоним и географические координаты.

![Карточка пространственной локализации](/assets/instruction/geo_card1.webp)

## Происхождение координат

Сначала выбираем происхождение координат:

- **Из источника (оригинальные)** — координаты приведены прямо в публикации. В этом случае нужно выбрать формат ввода (DD, DM или DMS) и ввести координаты.
- **Собственная геопривязка (волонтёр)** — вы самостоятельно определили координаты (например, по описанию места на карте). Можно выбрать точку на интерактивной карте.
- **Данные отсутствуют** — в публикации нет координат и вы не можете их определить. При проверке возникнет предупреждение — нажимайте «Да, всё верно».

## Административные данные

**Страна** — по умолчанию стоит Россия. Если публикация на английском языке, снимите галочку «Местоположение относится к Уралу» и введите название страны вручную на английском.

**Регион (субъект)** — область, республика или край. Форма предлагает только те районы, которые относятся к выбранному региону.

**Район** — более мелкие административные единицы. Если выбрать сразу район, то регион подставится автоматически.

> Если вы не нашли необходимый вариант в предложенном списке, или хотите внести из данной публикации все находки, а не только относящиеся к Уралу, то снимаем галочку *Местоположение относится к Уралу* и после этого вводим любые другие административные названия.

**Локалитет (топоним)** — записываем вручную в точности так, как оно указано в работе. Чаще всего это ближайший населённый пункт к тому месту, где была сделана находка, но могут быть названия заповедников, указание направления (4 км к югу от д. Макарово) и другие варианты.

![Карта Урала](/assets/instruction/adm.webp)

## Координаты

Если вы выбрали «Из источника», нужно указать формат ввода координат:

- **DD** — десятичные градусы (например, 55.7558, 37.6173)
- **DM** — градусы и минуты (например, 55°45.35' N, 37°37.04' E)
- **DMS** — градусы, минуты, секунды

![Форматы координат](/assets/instruction/geo.webp)

Введите координаты в соответствующие поля. Поле **Неопределённость, м** — расстояние в метрах, в пределах которого находится локалитет (обычно 30 м для современных GPS). Если значение неизвестно, оставляем поле пустым.

![Ввод координат](/assets/instruction/geo3.webp)

Если координаты приведены прямо в публикации, в **Географических примечаниях** укажите это.

![Географические примечания](/assets/instruction/geo2.webp)

## Собственная геопривязка

Если вы выбрали «Собственная геопривязка (волонтёр)», откроется интерактивная карта. Кликните на карте, чтобы поставить точку. Координаты подставятся автоматически.

![Интерактивная карта](/assets/instruction/map1.webp)

> Собственной геопривязкой на данном этапе развития проекта мы не занимаемся, так что у нас только два варианта: либо вносить координаты из публикации, либо не вносить. Если вы хотите заняться поиском координат, обратитесь к нам за инструктажем в индивидуальном порядке.

## Пресеты (копирование данных)

В правом верхнем углу карточки есть выпадающий список **Заполнить как в другой записи**. Если в текущей публикации уже есть другие записи с данными координатами или локацией, вы можете выбрать одну из них — и все соответствующие поля заполнятся автоматически.

![Пресеты локализации](/assets/instruction/preset1.webp)

## Пример заполнения

Поскольку публикация на английском, снимаем галочку *Вводить административные названия на русском языке*. Местоположение всегда указывается в разделе "Материалы и методы" публикации. В этой статье информация о Регионе отражена также в заголовке публикации. Значит, в качестве региона выбираем Оренбургскую область, предварительно сменив страну на английское название (Russia).

![Ввод региона](/assets/instruction/adm2.webp)

В данном примере перечисление конкретных мест сбора материала дано в разделе "Introduction" (Введение). Ниже в тексте статьи даются ссылки на соответствующие локалитеты в виде номеров в квадратных скобках.

![Поиск локалитетов](/assets/instruction/adm3.webp)

Если мы соотнесём эти номера с теми, что даны во введении, получится, что и первая, и вторая находки относятся к Кувандыкскому району. Место сбора вписываем вручную так, как оно указано в статье.

![Заполненный блок](/assets/instruction/adm4.webp)

# Параметры сбора материала

В карточке **Параметры сбора материала** вносится информация о дате, методе и обстоятельствах сбора.

![Карточка параметров сбора](/assets/instruction/event_card1.webp)

## Дата сбора

В поле **Дата сбора (как в статье)** записываем дату точно так, как она указана в публикации. Примеры: «19.08.2018», «19.08–02.09.2018», «лето 2017», «VIII.2019».

Если дата является интервалом, поставьте галочку **Дата является интервалом**.

![Ввод дат](/assets/instruction/eve1.webp)

**Точность даты** — день, неделя, месяц или год. Если в публикации не указан конкретный день, выбираем соответствующую точность.

## Коллектор

**Коллектор** — тот, кто собрал паука. Если в статье перечислены инициалы (например ТТК), ищем их расшифровку в тексте (Tuneva T.K.) и вносим полную информацию. Если авторы сбора не указаны, вносим авторов публикации.

## Метод сбора

**Метод сбора** — способ, которым был пойман паук (ловушки Барбера, кошение сачком, ручной сбор и т.д.).

## Объём выборки

**Объём выборки** и **Единица выборки** — усилие исследователя, затраченное на поимку пауков. Например: объём = 100, единица = ловушко-суток. Или: объём = 200, единица = взмахов сачком.

## Биотоп

**Биотоп** — это небольшой участок территории с однородными природными условиями, который обычно выделяют по преобладающим растениям (например, берёзовый лес, пойменный луг). Вносить в форму следует как можно более полную информацию о площадке.

![Биотоп пример 1](/assets/instruction/image25.webp)
![Биотоп пример 2](/assets/instruction/image26.webp)

Если биотопов несколько, разделяйте их точкой с запятой «;». Иногда вместо краткого названия пишут подробные описания — копируйте их в **Примечания к событию**.

## Примечания

В **Примечаниях к событию** стоит написать метод, которым материал собирался, если он указан в публикации, а также любую другую полезную информацию (погодные условия, особенности территории и т.п.).

![Пример заполнения блока](/assets/instruction/eve4.webp)

## Пресеты

Аналогично блоку локализации, в правом верхнем углу карточки есть выпадающий список для копирования данных параметров сбора из другой записи текущей публикации.

> Всю информацию вводим на языке оригинала публикации!

# Таксономическая принадлежность

В карточке **Таксономия** записываем латинские названия семейства, рода и вида пауков.

Мы имеем дело с отрядом Пауки (по-латински *Araneae* или *Aranei*). Отряды разбиваются на семейства, которые оканчиваются на *-idae* (например, Araneidae, Lycosidae). Семейства делят на рода, а рода на виды. Полное название вида выглядит, например, так: *Araneus diadematus Clerck, 1757*. Фамилию автора и год описания вносить никуда не надо.

![Таксономия в статье](/assets/instruction/tax1.webp)

## Поля формы

- **Семейство (Familia)** — начните вводить название, появятся подсказки. Подсказки загружаются с сервера.
- **Род (Genus)** — название рода. Подсказки появляются с учётом выбранного семейства.
- **Видовое название (эпитет)** — только эпитет, без рода. Подсказки появляются с учётом семейства и рода.

![Выпадающий список](/assets/instruction/tax2.webp)

Каскадные подсказки работают автоматически: сначала выберите семейство, затем род (список фильтруется по семейству), затем вид (список фильтруется по роду).

## Если вид не найден в списке

Если в выпадающем списке не найден нужный вид, ставим галочку **Латинское название введено вручную** и вводим название вручную. Такое может быть, если вид со времен выхода публикации был переименован.

![Ручной ввод](/assets/instruction/tax3.webp)

## Дополнительные поля

- **Ранг таксона** — род (genus), вид (species) или подвид (subspecies).
- **Типовой статус** — голотип, паратип и т.д. (указывается только если вид описан как новый).
- **Валидное название** — если приведённое в статье устарело, указываем современное название.
- **Таксономические примечания** — примечания ко всему таксону.
- **Примечания к идентификации** — примечания к определению.

В некоторых работах род может быть сокращён до одной буквы. В форму род и вид вносим полностью, без сокращений.

Если у паука удалось определить только род (указано *sp.*), оставляем поле видового названия пустым и снимаем галочку с **Вид определён**.

# Количественные характеристики

В карточке **Количественные характеристики** данные о количестве пауков вносятся с учётом их пола и возраста.

![Карточка количественных характеристик](/assets/instruction/quantity_card1.webp)

## Поля для ввода количества

| Пол | Описание |
|-----|----------|
| **Самцов** | Половозрелые самцы (♂, m) |
| **Субвзрослых самцов** | Молодые самцы, станут взрослыми после следующей линьки (sub.♂, sub. m) |
| **Самок** | Половозрелые самки (♀, f) |
| **Субвзрослых самок** | Молодые самки (sub.♀, sub. f) |
| **Взрослых (пол не определён)** | Половозрелые особи, пол не указан |
| **Ювенильных** | Неполовозрелые особи (juv.) |

Справа от полей отображается **автоматический подсчёт общего количества** особей в записи.

## Правила ввода

Количество вносим в форму как есть. Если количество пауков приведено без указания полов, всех особей записываем во **Взрослых (пол не определён)**. Если даны самцы и самки — пишем раздельно, **не суммируем**!

Количество экземпляров может быть не указано (например, только плюсик в таблице). По умолчанию в количество вносим 1 и пишем в **Примечаниях к образцам**: «наличие особей, а не их количество».

## Единицы измерения

Если указано не количество особей, а другой показатель численности, выбираем соответствующие единицы измерения:

- особей
- особей на 10 ловушко-суток
- особей на 100 ловушко-суток
- особей на м²
- балл обилия (по Песенко)
- особей на 10/20/100 взмахов сачком
- особей на 10 канаво-суток
- особей на 100 ловушек

Бывает, что в публикации приведены несколько показателей. Нам надо выбрать один. Попадаемость на 100 лов.-сут. приоритетнее, чем %, а непосредственное количество особей приоритетнее лов.-сут. Более значимый показатель вносим в форму, а в **Примечаниях к образцам** пишем менее значимый.

![Ввод количества](/assets/instruction/tax4.webp)

# Проверка и отправка записи

Когда все поля формы заполнены, проверьте статус записи в сайдбаре:

- **Зелёный индикатор (Готово)** — запись прошла валидацию и успешно отправлена.
- **Синий индикатор (Черновик)** — запись сохранена автоматически, но не отправлена. Нажмите кнопку **Отправить** внизу формы.
- **Красный индикатор (Ошибка)** — есть ошибки валидации. Исправьте отмеченные поля.

![Индикатор статуса внизу формы](/assets/instruction/footer1.webp)

Кнопка **Отправить** расположена в нижней панели формы. Она доступна только когда форма заполнена. При нажатии запись проходит серверную валидацию и, если ошибок нет, попадает в базу данных.

Если есть ошибки, система подсветит проблемные поля. Достаточно вернуться к ним и исправить — повторно вводить всё заново не придётся.

![Ошибки валидации](/assets/instruction/error1.webp)

# Завершение работы с публикацией

Когда вы посчитаете, что взяли из публикации все данные, которые могли, перейдите на страницу завершения. Это можно сделать двумя способами:

1. Кнопка **Завершить обработку** в сайдбаре (внизу списка записей).
2. Кнопка **Завершить обработку** на дашборде.

![Кнопка завершения в сайдбаре](/assets/instruction/sidebar_finish1.webp)

## Страница завершения

На странице завершения нужно заполнить форму с итоговой информацией о публикации:

![Страница завершения](/assets/instruction/submit1.webp)

### Уровень обработки

Выберите один из вариантов:

- **Полная** — все виды определены до вида.
- **Урал** — обработка ограничена Уралом.
- **Частичная** — часть видов не определена.
- **Пропуск** — публикация пропущена.

### Находки за пределами Урала

Укажите, есть ли в публикации находки за пределами Урала (Да / Нет).

### Указания видов без материала

Укажите, есть ли в публикации виды, указанные без материала (Да / Нет).

### Комментарий

Свободное поле для любых замечаний по публикации (максимум 1000 символов). Если у публикации были особенности (виды за пределами Урала, перечисление видов без находок), стоит об этом написать. Эта информация здорово облегчит дальнейшую работу с данными.

Нажмите **Завершить** для отправки. Публикация будет считаться полностью обработанной, а система предложит вам новую.

> Если вы не оставили ни одной записи, система предупредит и запросит подтверждение.

# Дополнительные возможности

## Пресеты (копирование между записями)

Пресеты позволяют копировать данные из одной записи в другую. Доступны для двух блоков:

- **Пространственная локализация** — копирует страну, регион, район, локалитет, координаты и т.д.
- **Параметры сбора материала** — копирует дату, коллектора, метод сбора, биотоп и т.д.

Выпадающий список **Заполнить как в другой записи** расположен в правом верхнем углу каждой карточки. Выберите запись-источник — и данные подставятся автоматически.

Это значительно ускоряет работу, когда из одной публикации вносятся многие находки с одинаковыми параметрами.

## Статистика

На странице **Статистика** вы можете посмотреть:

- Общую статистику проекта (количество обработанных публикаций, видов, волонтёров).
- Персональную статистику: количество внесённых записей, обработанных публикаций, уникальных видов и семейств.
- Графики динамики по времени.

Также доступен поиск статистики других пользователей.
